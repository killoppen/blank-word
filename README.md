# 空白格 · 单词学习

一个 Android 优先的单词学习 PWA。每行固定四个可编辑数据列：

1. 英文
2. 中文
3. 英文
4. 中文

第三、四列默认留空，用于复习时补写答案。学习模式可以选择遮盖英文或中文；复习词本会自动生成每日复习内容。

## 使用

- 点击“添加新行”或“批量添加单词”录入词对。
- 点击单元格编辑；手机端编辑时底部操作栏会自动收起，避免被键盘遮挡。
- 使用“学英语 / 学中文”切换遮盖方向。
- 打开“测验”进行逐题输入，完成后查看正确率和错题。
- 登录后可通过 Supabase 同步词本；不登录也可以使用本地词本。

## 安装到 Android

1. 通过 HTTPS 或 `localhost` 部署项目。
2. 使用 Android Chrome 打开 `index.html`。
3. 在页面出现安装提示时选择“安装到手机”；也可以通过 Chrome 菜单选择“添加到主屏幕”。

应用支持离线打开已缓存的页面资源。首次安装后建议联网打开一次，确保 Service Worker 完成缓存。

## 本地预览

静态文件需要通过 HTTP 服务打开，不能直接双击 HTML 文件：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/index.html`。

## 入口文件

- `index.html`：主应用入口。
- `空白格.html`：中文文件名入口，与主入口保持同步。
- `manifest.webmanifest`：PWA 安装配置。
- `sw.js`：离线缓存和版本更新。
- `icon.svg`：应用图标。
